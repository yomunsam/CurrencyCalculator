# 交互翻新验收

## 本轮实现

- 货币选择器：当前语言、英文名称、代码即时筛选；最近使用最多 3 项，剩余法币与加密币各按代码排序；无重复展示。
- 布局按宽度切换：窄屏底部面板，宽屏居中对话框。标题和搜索固定，列表滚动；关闭后归还焦点。
- 清空按钮保持固定，清空当前编辑金额时保留焦点。
- 行左侧拖柄兼操作菜单入口；鼠标右键、键盘菜单键或 Shift+F10 可打开菜单。金额输入框保留原生右键编辑菜单。
- 触控在币种信息或行空白处左滑展开删除，右滑或点击外部收起。输入框保留选区操作，拖柄负责纵向排序；最少保留 2 项。
- 取消拖动、捕获丢失不会提交；隔离其他指针。排序与删除按对象保持活动行和编辑行，切换币种不会重建整行。

## 已验证

- .NET 构建：0 警告、0 错误。
- Node 内置测试：7 项通过，覆盖取消/捕获丢失、后续拖动恢复、其他指针干扰、非主按钮、左滑只展开、单行展开、纵向滚动与输入框排除、最少行数限制。
- 桌面浏览器：中文名称与英文名称搜索、无结果状态、分组、关闭与焦点返回、右键菜单、键盘菜单排序、鼠标拖动、添加后删除、清空保留输入焦点。
- 布局检查：桌面居中弹窗、390×844 视口底部面板。

Node 测试模拟 DOM 边界，只验证事件状态规则，不模拟浏览器原生滚动和系统键盘。

## 留给实际设备的检查

1. 触屏在币种信息处左滑，确认只展开按钮，再点击删除；右滑/点击别处关闭，不能与纵向滚动冲突。
2. 输入框内选中文字、拖柄排序、连续快速换行、多指接触、系统中断手势后恢复。
3. 同一设备交替使用触控、鼠标、实体键盘，确认入口可共存；iOS/Android 的键盘与焦点行为。
4. 浅色主题及窄屏搜索时系统键盘弹出后的可视区域。

本轮没有实现内置计算器键盘，也没有调整弱网数据加载；发布版 PWA 离线与更新不属于本轮验证结论。
